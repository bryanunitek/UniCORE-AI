## Why this file exists at all

The Singular Pairing Principle is referenced from this repository (UniCORE-AI) and from the wider corpus. Keeping a numbered file (`10001-`) in this repository's `docs/` folder preserves the cross-reference anchor that earlier corpus documents already point at.

The body has been shrunk to this pointer, deliberately, to eliminate the three-way drift that arose when the same doctrine was edited as three independent copies in three foundation-triad repositories. Drift between three forks of the same doctrine is itself an instance of the Inconsistency Problem the doctrine is designed to prevent. One canonical home, sister pointers, no drift.
